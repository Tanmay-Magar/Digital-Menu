GOKUL DIGITAL MENU
==================

Contents
- index.html: responsive digital menu website
- assets/menu-1.webp ... menu-9.webp: the nine supplied menu pages

Preview locally
1. Extract this folder.
2. Open index.html in a browser.

Free hosting with GitHub Pages
1. Sign in to https://github.com and create a public repository named gokul-digital-menu.
2. Upload index.html and the complete assets folder (keep the folder structure).
3. Open repository Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select branch main and folder /(root), then Save.
6. Wait for GitHub Pages to publish. It will show your public website URL.

QR code
A permanent QR code must point to the final published URL. Once you have the GitHub Pages URL,
create the QR code using any QR generator and test it on two different phones before printing.
Do not print a QR code pointing to a temporary preview or local file.

Menu accuracy note
The supplied nine menu pages are preserved as images. This avoids guessing at small or stylised
text and keeps every listed item and price as shown in the original artwork. Tap any page on
the website to enlarge it.
